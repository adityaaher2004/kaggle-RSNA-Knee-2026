# Proposed `quartz` worktree structure

This is a **proposed** minimal-but-complete project, not the current on-disk repository. It intentionally reuses the existing `src/oxalpha` namespace, `pyproject.toml`, `config.py`, and EDA tests. It does **not** create an independent top-level package. `contracts.yaml` is machine-readable and drives generated contract code; `SPEC.md` describes algorithmic decisions.

## Deliberate differences from uploaded `tree.txt`

1. Keep `src/oxalpha` and working `config.py` instead of another package. Existing stub files `fusion.py`, `itc.py`, `auxiliary.py`, `text_encoder.py`, `train_stage_a.py/b.py/c.py` are **not** required by the main runtime; archive/delete only after checking imports/commits, and do not keep broken import-time stubs in the deploy package.
2. New `labels/` package is mandatory: with 98.7% unlabeled `train.csv`, Muse Glimmer ingestion is first-class, not scattered training script logic.
3. `generated/` and `specs/contracts.yaml` make spec-as-source verifiable. Git/CI **fails** on stale generated labels/metadata/IO contracts.
4. `data/selection.py`, `metadata.py`, `cache.py` separate safety/physics and performance policies; both Train and Kaggle use identical preprocessing.
5. One training engine with stage configs avoids three divergent loops; optional KD remains training-only and never imported by inference.
6. Add `slurm/` to exploit Quartz allocation without assuming partition/account. `notebooks/kaggle_inference.ipynb` is the only contest-submission entry.
7. Keep `work/` ignored, `results/` sanitized and tracked. Never commit original report/DICOM/credentials or existing HF tokens. Preserve prior branch; do not push.
8. Rebuild tests around **failure paths**: signed/rescaled DICOM, duplicate slices, lost codecs, independent fluid/fat flags, corrupt series, hidden test shape variation, labels missing, and 58-gold exclusion.

## Import boundary (enforced in CI)

```text
oxalpha.inference -> data, models.student, generated, config
oxalpha.training  -> inference-safe core + losses + labels + optional teacher
oxalpha.labels    -> Glimmer output and report QA, never inference
```

An inference import of `transformers`, `labels`, `teacher`, report text, `train.csv` or `.env` is a test failure. `Student.forward` never gets a `Report`, label, or label-derived slot.
